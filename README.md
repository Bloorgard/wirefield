# WIRES

WIRES — локальный визуальный редактор физических жгутов. Он работает как статическая веб-страница, хранит рисунок в браузере и поддерживает человекочитаемый формат `.wires`.

Live-версия: <https://wires.pustota.link/>

## Возможности

- SVG-холст с сеткой и физической анимацией;
- выбор и перемещение жгутов;
- перемещение начальной точки и хвоста;
- закрепление хвоста;
- кисть и ластик;
- слои, мультивыбор и изменение порядка;
- копирование объекта через `Alt` или `Option`;
- pan и zoom;
- темы фона и сетки;
- undo до 10 последних изменений;
- локальное сохранение в `localStorage`;
- импорт и экспорт `.wires`;
- мобильная панель слоёв.

## Быстрый запуск

Для локального просмотра нужен Python 3:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8765/>.

Для smoke-test нужен Node.js и доступный Chromium:

```bash
npm test
```

Тест сам поднимает локальный HTTP-сервер и завершает временный профиль браузера после прогона.

## Хранение данных

Основной рисунок хранится в `localStorage['wires-v2']`. Вид холста хранится отдельно в `localStorage['wires-view-v1']`. Параметры кисти используют ключи `wires-brush-length` и `wires-brush-color`.

Приложение не отправляет рисунок на сервер. Экспорт `.wires` нужен для резервной копии и переноса между браузерами.

## Ограничения MVP

- нет аккаунтов и совместного редактирования;
- нет серверного хранения;
- undo хранит до 10 состояний и живёт только в текущей вкладке;
- настоящие touch-жесты нужно проверять на физическом телефоне отдельно от синтетического QA;
- исходный код пока собран в одном `index.html`.

## Публикация

WIRES публикуется как один статический файл `index.html`. В репозитории тесты и документация не входят в live-раздачу. Для операционной процедуры публикации используется `deployctl` на хосте проекта.
