# Архитектура

## Общая схема

WIRES — статическое приложение без backend и внешнего состояния. HTML, CSS и JavaScript находятся в `index.html`.

```text
index.html
├── разметка панели и SVG-холста
├── CSS desktop/mobile layout
└── JavaScript
    ├── модель рисунка
    ├── localStorage
    ├── parser/serializer .wires
    ├── UI и слои
    ├── pointer/keyboard interactions
    └── physics loop
```

Smoke-test находится отдельно в `tests/smoke.mjs` и управляет Chromium через CDP без npm-зависимостей.

## Модель данных

Состояние рисунка имеет вид:

```js
{
  version: 1,
  cell: 44,
  background: '#f200e9',
  pointsMatchBackground: false,
  gridVisible: true,
  wires: [
    {
      id: '0001',
      x: 7,
      y: 2,
      length: 10,
      color: '#102cff',
      endX: 20,
      endY: 7
    }
  ]
}
```

`endX` и `endY` присутствуют только у закреплённого хвоста.

## Runtime-физика

Для каждого жгута создаётся runtime-состояние с массивом внутренних точек. Стартовая точка и закреплённый хвост выступают ограничениями. Внутренние точки обновляются Verlet-подобным шагом с гравитацией, демпфированием и несколькими проходами коррекции расстояния между соседними точками.

После drag запускается release-фаза на 90 кадров. Объект не засыпает, пока движутся внутренние точки. В idle-состоянии SVG-путь не пересчитывается без необходимости.

При `prefers-reduced-motion: reduce` физическая анимация заменяется прямой интерполяцией между концами.

## Взаимодействия

Pointer-события разделены по типам:

- тело жгута: drag всего объекта;
- стартовая точка: изменение начала;
- tail hit area: перемещение или закрепление хвоста;
- пустой холст: pan или рамка выделения;
- кисть и ластик: обработка клеток между предыдущей и текущей точкой;
- grip слоя: изменение порядка.

`pointercancel` отменяет незавершённый drag и восстанавливает состояние до начала действия.

## Persistence

| Ключ | Назначение |
|---|---|
| `wires-v2` | модель рисунка |
| `wires-view-v1` | pan и zoom |
| `wires-brush-length` | длина кисти |
| `wires-brush-color` | цвет кисти |

Undo хранит JSON-снимки модели в памяти вкладки. В persistent storage история undo не записывается.

## Нормализация

`normalize()` используется при загрузке, импорте и undo. Она проверяет границы, фон, длину, координаты и занятые позиции. Импорт и загрузка сообщают пользователю, если нормализация изменила данные.

## Безопасность

- значения ID и цветов проверяются до использования;
- пользовательские ID вставляются в DOM через `textContent`;
- импорт ограничен 1 МБ;
- parser не исполняет содержимое `.wires`;
- Clipboard API имеет fallback без выполнения текста документа.

## Текущая граница рефакторинга

Монолитный `index.html` пока сохранён намеренно. Следующим безопасным этапом можно вынести чистые части в отдельные модули:

1. `wires-format.js` для parser/serializer;
2. `model.js` для normalize и persistence;
3. `physics.js` для runtime и tick;
4. `interactions.js` для pointer и keyboard;
5. `ui.js` для панели и слоёв.

Сначала должны появиться тесты на чистые функции. Разделение файла без тестового покрытия увеличит риск регрессий.
