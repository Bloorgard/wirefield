# Формат `.wires`

`.wires` — текстовый формат рисунка. Файл предназначен для чтения человеком, резервного копирования и переноса рисунка между браузерами.

## Канонический вид

```text
wires 1
canvas 44 #f200e9
points white
grid visible

wire 0001 x 7 y 2 length 10 color #102cff
wire 0002 x 12 y 4 length 9 color #102cff
wire 0003 x 16 y 1 length 11 color #102cff end 20 7
```

Экспорт всегда записывает заголовки `canvas`, `points` и `grid`, затем пустую строку и строки жгутов.

## Заголовки

Первая непустая строка должна быть:

```text
wires 1
```

Поддерживаемые параметры:

```text
canvas CELL BACKGROUND
points white|wire|background
grid visible|hidden
```

Допустимые значения:

- `CELL`: число от 24 до 80;
- `BACKGROUND`: `#f200e9`, `#102cff` или `#ffffff`;
- `points white`: точки используют контрастный цвет интерфейса, белый на розовом и синем фоне и синий на белом;
- `points wire`: каждая точка получает цвет своего жгута;
- `points background`: точки окрашиваются как фон;
- устаревший импортируемый режим `points interface` читается как `points white`;
- `grid visible` и `grid hidden`: состояние сетки.

Если `canvas`, `points` или `grid` отсутствуют, загрузчик использует значения по умолчанию. Канонический экспорт всегда включает их.

## Строка жгута

Свободный хвост:

```text
wire ID x X y Y length L color #RRGGBB
```

Закреплённый хвост:

```text
wire ID x X y Y length L color #RRGGBB end EX EY
```

Поля должны идти в указанном порядке. `end` разрешён только полной парой координат.

### Поля

| Поле | Значение |
|---|---|
| `ID` | 1–64 символа: `A-Z`, `a-z`, `0-9`, `_`, `-` |
| `X`, `Y` | неотрицательные координаты до 100000 |
| `L` | длина от 0 до 48 клеток |
| `#RRGGBB` | шестизначный hex-цвет |
| `EX`, `EY` | неотрицательные координаты закреплённого хвоста до 100000 |

ID внутри одного файла должны быть уникальными. Максимум — 1000 жгутов. Размер файла — 1 МБ.

## Комментарии и пробелы

Пустые строки игнорируются. Строки, после удаления начальных пробелов начинающиеся с `#`, считаются комментариями.

Например:

```text
wires 1
# резервная копия от 2026-08-06
canvas 44 #f200e9
```

Лишние токены в строке жгута запрещены. Следующая строка отклоняется:

```text
wire A x 1 y 1 length 1 color #102cff EXTRA
```

## Нормализация

После синтаксической проверки приложение нормализует данные:

- координаты округляются к клеткам и ограничиваются допустимым диапазоном;
- занятые стартовые клетки разводятся на свободные позиции;
- длина ограничивается диапазоном 0–48;
- закреплённый жгут получает минимальную длину, достаточную для расстояния между концами;
- неизвестные или некорректные значения заменяются безопасными значениями.

Если нормализация изменила импортированный или сохранённый документ, приложение показывает уведомление. Для переносимости рекомендуется использовать канонический экспорт.

## Ошибки

Импорт отклоняется, если:

- первая строка не `wires 1`;
- команда неизвестна;
- структура строки `wire` нарушена;
- ID повторяется;
- число не является конечным числом;
- координата, длина или цвет выходят за ограничения;
- цвет не соответствует `#RRGGBB`;
- превышен лимит жгутов или размер файла.

Сообщение содержит номер строки, когда ошибка относится к конкретной строке.
